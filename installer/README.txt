Magical Blocks  (unofficial, Windows x64)

YOU MUST SUPPLY YOUR OWN LEGALLY DUMPED ROM OF THE GAME. WE DON'T PROVIDE IT.
You need the USA version of Magical Tetris Challenge (Nintendo 64), usually a .z64, .v64 or .n64 file.

HOW TO PLAY
1. Start MagicalBlocks.exe (or use the Start menu if you used the installer).
2. If it asks for a ROM, click "Select ROM" and pick your ROM file. You only do this once.
3. Click "Start game".

SHADERS (optional)
1. In the game, press Esc. The settings menu opens.
2. Click Graphics.
3. Pick a shader in the "Shader" list. Pick "None" to turn it off.

KEYS
Enter = Start. Space = A. Left Shift = B. J/L/I/K or W/A/S/D = move.
In menus, press A (Space) to choose. Gamepads work too.
Player 2: a second gamepad, or the number pad (Enter = Start, 0 = A).

IF SOMETHING GOES WRONG
- "This file can't be used": you need the USA version of the game. Try another dump of it.
- Black screen or no start: update your graphics driver.
- "Windows protected your PC": click "More info", then "Run anyway".
